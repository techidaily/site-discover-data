## Unleash Your Potential with New DeX 3 (Pro Edition) v3.9.0.6 DJ Mixing Software Now Ready!

[![DEX 3.9.0.6 DJ mixing software update](https://i0.wp.com/pcdj.com/wp-content/uploads/2017/10/dex3906-coverimage.jpg?resize=706%2C321&ssl=1)](https://i0.wp.com/pcdj.com/wp-content/uploads/2017/10/dex3906-coverimage.jpg?fit=706%2C360&ssl=1 "DEX 3.9.0.6 DJ mixing software update")

**Version 3.9.0.6 of [DEX 3 mixing software](https://tools.techidaily.com/pcdj/products/) is ready for download.**

Version 3.9.0.6 is a [DEX 3](https://tools.techidaily.com/pcdj/products/) maintenance release with a slathering of squashed bugs and a few performance improvements for the new built-in [Party Tyme Karaoke Subscription Service](https://tools.techidaily.com/pcdj/products/). This free update (they all are!) for existing DEX 3 customers doesn’t include exciting new mixing features (sorry folks) but we’ve got plenty of that coming down the pipe soon enough. (We’re also knee deep in development of the new tablet version of DJ DEX, but shhhh…)

[VIEW LARGER IMAGE ![DEX 3.9.0.6 Mixing Software Screen Shot](https://i1.wp.com/pcdj.com/wp-content/uploads/2017/10/dex3906-pt-screenshot.jpg?fit=300%2C169&ssl=1 "DEX 3.9.0.6 Mixing Software Screen Shot")](https://i1.wp.com/pcdj.com/wp-content/uploads/2017/10/dex3906-pt-screenshot.jpg?fit=1030%2C579&ssl=1)

What version 3.9.0.6 does include is a better [Party Tyme Karaoke Subscription](https://tools.techidaily.com/pcdj/products/) experience. That’s something to sing about if you’re a DJ/KJ hosting karaoke with DEX 3 with the HD karaoke online/offline streaming service. Searching, streaming and downloading from the Party Tyme Karaoke Subscription service should be snappier, and those new customers experiencing issues logging in after creating user names IN ALL CAPS should no longer have an issue. Sorry about that, it was annoying!

If you missed the 3.9.0.5 announcement, [Party Tyme Karaoke](https://tools.techidaily.com/pcdj/products/) is now built into DEX 3, providing subscribers of the commercially legal service in-app access to and HD catalog of older classics and brand new karaoke hits for $99-a-month. It’s the robust karaoke library karaoke hosts and karaoke bars need to fill ever singer request, with brilliant high-resolution lyrics and weekly updates so the library stay’s fresh.

As always, the DEX 3.9.0.6 update will install directly over-top your existing [DEX 3](https://tools.techidaily.com/pcdj/products/) version, keeping all your lists, data and settings intact.
